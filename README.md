# Andreea Onu Portfolio

Static portfolio built with Vite. Sharp optimizes build images without changing source assets.

```sh
npm ci
npm run dev      # Local development
npm run build    # Production output in dist/
npm run preview  # Preview the build
npm run deploy   # Publish to the linked Netlify site
```

Deployment requires Netlify login. Enable Netlify form detection to receive `connect` submissions.
